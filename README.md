# 🌐 GCES App

A Django-based web application developed as a Minor 2 project.  
This project is designed to demonstrate full-stack web development using Django, including backend logic, database integration, and dynamic content rendering.

---

## 📌 About

The GCES App is a web-based system built using Django that focuses on managing and displaying structured data through a user-friendly interface.

This project was developed to:

- Apply Django framework concepts in a real-world application  
- Understand backend development and MVC (Model-View-Template) architecture  
- Work with databases and dynamic web pages  
- Build a scalable and maintainable web application  

---

## 🎯 Objective

- To develop a full-stack web application using Django  
- To implement CRUD operations with database integration  
- To understand routing, templates, and models in Django  
- To enhance backend and web development skills

## 🚀 Features

## ⚙️ How It Works

1. User accesses the web application through a browser  
2. Django handles requests via URL routing  
3. Views process logic and interact with models  
4. Data is stored and retrieved from the database  
5. Templates render dynamic content to the user

## ▶️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/PramishBytes/Gces-App.git
cd Gces-App
```

### 2. Create Virtual Environment (optional)

```bash
python -m venv venv
source venv/bin/activate   # (Linux/Mac)
venv\Scripts\activate      # (Windows)
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run Migrations

```bash
python manage.py migrate
```

### 5. Start the Server

```bash
python manage.py runserver
```

### 6. Open in Browser

```
http://127.0.0.1:8000/
```
